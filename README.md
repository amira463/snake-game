# Snake

A classic Snake game built with plain JavaScript and the HTML canvas. No libraries, no build step.

**Live demo:** add your Vercel link here

## Features
- Smooth grid-based movement that speeds up as your score grows
- Keyboard controls (arrow keys or WASD), Space to pause
- Swipe and on-screen buttons for phones
- Best score saved in the browser
- Light and dark themes that follow your device

## Run it locally
Open `index.html` in any modern browser.

## Deploy
Push to GitHub, then import the repository on Vercel (framework preset: Other, no build command).

## What I learned
- Building a game loop with `setTimeout`
- Collision detection on a grid
- Drawing with the Canvas 2D API
